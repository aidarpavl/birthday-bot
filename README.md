# Туған күндер

- **Сайт (Streamlit):** за день до дня рождения показывает напоминание, в сам день показывает статус поздравлений и кнопки.
- **Рассылка и бот (GitHub Actions):** каждый час с 09:17 до 21:17 по Казахстану подключает новых людей к боту и поздравляет сегодняшних именинников. Уже отправленное не повторяется. Сайт для этого открывать не нужно.

Текст: `ФИО сізді туған күніңізбен құттықтаймыз!!!`

Столбцы таблицы по порядку: A №, B ФИО, C дата `ДД.ММ.ГГГГ`, D телефон, E логин Instagram, F логин Telegram. Год рождения при сравнении не учитывается.

## Настройка

### 1. Таблица
«Настройки доступа» → «Все, у кого есть ссылка» → **Читатель**. Сейчас по ссылке её может менять любой, а рассылка доверяет этим данным.

### 2. Бот
1. В Telegram откройте @BotFather, отправьте `/newbot`, задайте имя и логин бота.
2. Скопируйте токен. Он даёт полный доступ к боту: храните его только в секретах.

### 3. GitHub
Создайте **приватный** репозиторий и загрузите проект в его корень. Секреты добавляются в Settings → Secrets and variables → Actions:

| Секрет | Для чего | Где взять |
|---|---|---|
| `SHEET_ID` | таблица, обязательно | часть ссылки между `/d/` и `/edit` |
| `SHEET_GID` | лист, если не первый | значение `gid=` в ссылке |
| `TELEGRAM_BOT_TOKEN` | Telegram | @BotFather |
| `MOBIZON_API_KEY` | SMS | кабинет mobizon.kz → API |
| `MOBIZON_SENDER` | имя отправителя, если зарегистрировано | кабинет Mobizon |
| `INSTAGRAM_SESSION` | Instagram | `python tools/instagram_login.py` |

Канал без секретов просто не запускается, поэтому можно подключать их по одному.

### 4. Сайт
На share.streamlit.io создайте приложение: репозиторий, ветка `main`, файл `app.py`. В Advanced settings → Secrets вставьте:

```toml
APP_PASSWORD = "придумайте-пароль"
SHEET_ID = "id-вашей-таблицы"
TELEGRAM_BOT_TOKEN = "токен-от-BotFather"
```

`SHEET_ID` должен точно совпадать с секретом в GitHub: от него зависит список подключившихся к боту.

### 5. Проверка
Actions → «Поздравления» → Run workflow. Галочка «Пробный запуск» стоит по умолчанию: ничего не отправится, в логе будет видно, кого поздравили бы. Без галочки сообщения уйдут по-настоящему.

## Как работают каналы

**Telegram.** Бот не может написать первым и не находит людей по номеру, поэтому каждый человек должен один раз открыть ссылку на бота и нажать Start. Ссылка и список тех, кто ещё не подключился, есть на сайте.
- Если логин человека указан в столбце F, этого достаточно.
- Если логина нет, бот попросит отправить номер кнопкой, и он будет сверен со столбцом D. Принимается только собственный номер.
- Бот отвечает при ближайшем запуске, то есть с задержкой до часа, а ночью до утра.
- Если именинник нажмёт Start в течение дня, поздравление уйдёт при следующем запуске.
- Кнопка «Открыть чат в Telegram с готовым текстом» работает без бота: вы отправляете сообщение сами.

**SMS.** Через Mobizon, платно. В сообщении кириллицей 70 символов на один SMS, поэтому длинные ФИО занимают 2 SMS.

**Instagram.** Официальный API не даёт написать первым: человек должен сам написать аккаунту за последние 24 часа. Автоотправка здесь идёт через неофициальную библиотеку `instagrapi`. Это нарушает правила Instagram: аккаунт могут временно ограничить или заблокировать, вход с серверов GitHub может требовать подтверждения, а библиотека может перестать работать после изменений Instagram. Если вы не задаёте `INSTAGRAM_SESSION`, автоотправка выключена, а на сайте есть кнопка, открывающая чат, и готовый текст.

## Защита
- `sent_log.csv` хранит только № из таблицы, канал и статус. `telegram_users.csv` хранит ключи вместо телефонов и логинов, а также номера чатов.
- Одно и то же сообщение не уйдёт дважды. Если сервис не ответил вовремя, статус будет `uncertain`, и повтора не будет: проверьте вручную. После ошибки будет не больше 3 попыток в день.
- Если нажать кнопку на сайте до запуска рассылки, рассылка отправит сообщение ещё раз: бот не видит историю чата.
- Если именинников в один день больше 10, рассылка отменяется. Лимит меняется через переменную окружения `MAX_RECIPIENTS_PER_DAY`.
- Если отправка не удалась, запуск в Actions станет красным, и GitHub пришлёт письмо.
